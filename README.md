# Source

The project uses the breast cancer dataset obtained from Kaggle.

Download the CSV file from Kaggle and save it locally.

The expected columns include:

- `id`
- `diagnosis`
- 30 numerical tumour-related features

Diagnosis labels:

- `B` = Benign
- `M` = Malignant
